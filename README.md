# 12星座 占い 🌙

お誕生日を入れるだけで、あなたの星座カードを **1枚** お届けするWeb占いです。
SNSシェア（X / Instagram）とLINE友だち追加に対応し、**お一人さま一度だけ**利用できます。

## 機能

- **誕生日から星座を自動判定** — 日付を選ぶと、12星座のうちあなたの1枚を表示します。
- **結果は星座カード1枚** — 同梱の12星座イラスト（`assets/zodiac/`）から該当の1枚を表示します。
- **SNSシェア** — X（旧Twitter）への投稿、Instagramアカウントへの誘導、リンクのコピーに対応。
- **LINE友だち追加** — 公式アカウントへの登録ボタンを設置。
- **一人に一度だけ** — 端末（ブラウザ）の `localStorage` に記録し、再訪時は前回の結果のみ表示します。

## セットアップ（リンク先の設定）

`js/config.js` の値を、実際のURLに差し替えてください。ここだけ書き換えればOKです。

| 項目 | 内容 |
|------|------|
| `shareBaseUrl` | このアプリの公開URL（シェアリンクに使用）。空なら現在のページURLを自動使用 |
| `lineAddUrl` | LINE公式アカウントの友だち追加URL（`https://lin.ee/...` など） |
| `xAccountUrl` | Xアカウントのプロフィールリンク |
| `instagramUrl` | Instagramアカウントのリンク |
| `shareText` | シェア文言（`{sign}` が星座名に置き換わります） |
| `oncePerPerson` | `true` で一度だけ制限を有効化（テスト時は `false`） |

## 動作確認（ローカル）

```bash
# 任意の静的サーバーで開く
python3 -m http.server 8000
# → ブラウザで http://localhost:8000 を開く
```

> ⚠️ `localStorage` を使うため、`file://` 直開きではなくサーバー経由で開いてください。

## メモ

- 「一人に一度だけ」は端末ローカル（localStorage）での制限です。別の端末・ブラウザ、または履歴削除でリセットされます。厳密な本人単位の制限が必要な場合は、LINEログインなどのサーバー連携が必要です。
- Instagramは仕様上Webから直接フィード投稿ができないため、アイコンはアカウントへの誘導リンクにしています。
