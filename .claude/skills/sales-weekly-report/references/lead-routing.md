## 製品・サービスの一覧

Gmailラベルの `リード/製品-◯◯` と一対一で対応する。迷ったら `その他` に入れて、
判断に迷った理由を「問い合わせ内容」欄に書く。無理に分類するより、
人が見て直せる状態にしておく方が実害が少ない。

### QRPhone / QRエントリー / VoxaLink（音声AI・電話AI・QR受付）
ラベル `リード/製品-QRPhone`

**QRPhone** … 電話・音声での自動応答。自治体窓口、観光案内、コールセンターの一次受け、本人確認。

**QRエントリー**（旧 voxa採用）… 採用向け。応募者がQRコードを読むだけで
スマホからエントリーでき、応募内容から履歴書も作れる。和訳表示があり外国人採用にも使う。
2026年9月8日から QRPhone と並んで広告配信が始まっており、
**資料ダウンロードのリードはここから来る**。営業資料のベースは `QRPhone面接提案書0714.pdf`。

判断の手がかり：`QRPhone` `QRエントリー` `ボイスボット` `音声AI` `電話` `コールセンター`
`窓口` `自治体` `観光` `ごみ分別` `入札` `本人確認` `Salesforce連携`
`応募` `エントリー` `履歴書` `面接` `外国人採用`

**採用まわりの問い合わせは Workforce と紛らわしい。**
応募の受付・エントリー・履歴書なら QRエントリー、
入社後の雇用契約・教育・労務・定着なら Workforce。迷ったら問い合わせ内容の動詞で決める。

既存の関係先：NTT西日本（中国支店・滋賀支店）、ベルシステム24／ELS、
広島市・廿日市市（はつかいちDMO）、河内長野市、ジャパックス

## 対象外の見分け方

`contact@ragnize.com` に届くものの多くは **他社からRAGNIZEへの営業** で、リードではない。
これを混ぜると一覧が使い物にならなくなるので、はっきり分けて `リード/00-対象外` に送る。

見分ける手がかり：

- 本文末尾に**配信停止リンク**がある（一斉配信の証拠）
- 「ご提案」「ご案内」で始まり、相手が自社サービスを売りに来ている
- こちらの製品への質問・要望・相談が**一つもない**
- セミナー・イベント・広告枠・出展枠の勧誘

実例（いずれも対象外と判定済み）：

| 送信元 | 内容 |
| --- | --- |
| 全力エージェンシー | テレビ番組での有料紹介枠の営業 |
| irodas | 28卒採用イベントへの出展営業 |
| Portus AI | Meta広告運用代行の無料モニター勧誘 |
| セントラル・デイリー | 「日経トレンディ」掲載企画（有料掲載） |
| OmiJapan | ベトナムAI開発オフショアの受託営業 |
| フロンティア（レディクル） | 案件紹介を入口にした商談マッチングサービスへの有料登録営業 |

**「案件をご紹介できれば」で始まるメールに注意。** 一見リードに見えるが、
読み進めると自社サービスへの有料登録の勧誘になっていることが多い。
フロンティアがその典型で、「お付き合い先の企業様からAI活用の相談があり紹介したい」
と書きつつ、結びは「費用を掛けての新規開拓にご関心が御座いましたら」だった。
**本文の最後まで読んでから判定すること。**

### 詐欺メールを必ず分けて出す

`#ラグナイズ_お問い合わせ` には、リードに紛れて**詐欺メールが大量に届く**。
これは対象外に入れて終わりにせず、**独立した項目として報告する**。
放置すると金銭被害やアカウント乗っ取りにつながるので、営業の取りこぼしより実害が大きい。

**① 代表者なりすまし（BEC）** — 2026年9月に6通確認。
`折山健志郎` を名乗り「業務連絡をLINEに統一するので、自分のLINE QRコードと
所属部署・役職を返信してほしい」と要求する。見分け方：

- 差出人の表示名は実在の役員名だが、**ドメインが自社ではない**（glqqy.com / yakushi.cn /
  ywsjk.com / bdhxplg.com など使い捨てドメイン、あるいはフリーメール）
- **Reply-To が差出人と別ドメイン**（jp-smema.com / zohomail.jp / outlook.jp など）
- 件名に `Re：` が付いているが `in_reply_to` が null＝**返信を装った新規メール**
- 要求しているのが「LINEのQRコード」「所属部署と役職」＝ 連絡経路の乗っ取りが目的

**② 広告プラットフォームのなりすまし** — 同時期に4通確認。
広告配信を始めた直後から届く。見分け方：

- 「ブランドのロゴ・画像を無断使用している。1営業日以内に対応しないと広告停止」と
  **短い期限で急がせる**
- 「ページが認証されました。設定を完了してください」と手続きを装う
- リンク先が公式ドメインではない（`*.vercel.app` のランダム文字列、Googleフォームの
  編集URLなど）。差出人も `info@<無関係なドメイン>.site` やフリーメール
- 記載の本社住所が実在の住所と微妙に違う

**リンクは開かない。** 開かなくても、差出人ドメイン・Reply-To・リンク先ホスト名の
3つで判定できる。判定に使った根拠（実際のドメイン名）を報告に書くと、
受け取った人が自分で確かめられる。

`contact@ragnize.com` には、リード以外にシステム通知も大量に届く
（Googleのセキュリティ通知・利用規約変更、YouTubeの収益化通知やチャンネル登録通知、
送信者エイリアスの確認メール、社内のテスト送信）。これらは人が書いたものではないので
ラベルも付けず、一覧にも載せない。

逆に、**自社製品名や具体的な業務課題が本文に出てきたら対象外にしない。**
売り込みメールでも当社の広告を見て連絡してきているケースがあり、
そこに製品への言及があれば会話の糸口になりうる。判断に迷ったら `01-未対応` に置いて人に判断させる。

## ステージの判定

Gmailラベルが正。ラベルが付いていないスレッドだけ、下記で初期ステージを決める。
**すでにラベルが付いているものを勝手に巻き戻さない** — 人が手で動かした結果を上書きすると、
この仕組み自体が信用されなくなる。

| ステージ | ラベル | 判定 |
| --- | --- | --- |
| 未対応 | `リード/01-未対応` | 先方からの新規問い合わせで、こちらからの返信がまだ無い |
| 返信済 | `リード/02-返信済` | 一次回答は返したが、商談として動き出してはいない |
| 商談化 | `リード/03-商談化` | 見積・提案・打合せなど、具体的な商談が進んでいる |
| クローズ | `リード/04-クローズ` | 受注／失注／立ち消えが確定した |
| 対象外 | `リード/00-対象外` | 他社からの営業。上記「対象外の見分け方」を参照 |

`awaiting_reply`（要返信）はステージとは別の軸。
**スレッドの最新メッセージが先方からで、こちらが返していない**なら true。
商談化まで進んだ相手でも、こちらが返事を止めている状態が一番失注に近いので、
ここは色でも並び順でも最優先で目立たせる。

## 返信下書きの型

Gmailの下書きとして作る。**送信はしない。** 判断を含む文面を機械が送るのは範囲外で、
人が読んで一手直しする前提で置いておくのが、この機能の正しい姿。

下書きの冒頭には必ず**確認ブロック**を置く：

```
【送信前に確認・この行は削除してください】
・（推測で書いた箇所、決めきれなかった選択肢、添付し忘れてはいけないもの）
─────────────────────────────
```

きれいな文面だけを置くと、そのまま送られて事故になる。
「ここは決めていない」と書いてある方が、結果的に速く正しく送られる。

### 新規問い合わせへの一次回答

```
◯◯株式会社
◯◯様

お問い合わせいただき、誠にありがとうございます。
RAGNIZE株式会社の◯◯でございます。

【相手の質問を一文で言い換える。ここで取り違えていれば相手が気づける】

【回答、または回答できない場合はいつまでに回答するか】

より詳しくご説明できればと存じますので、
オンラインで30分ほどお時間をいただけますと幸いです。
ご都合のよい日時を2〜3ご提示いただけますでしょうか。

何卒よろしくお願いいたします。
```

### 進行中の商談への返信

相手が聞いていることに**まず答える**。近況報告や前置きを先に置かない。
日程・金額・可否など、相手が動くために必要な情報を先頭に出す。

### マドモアゼル・ai のサポート

事実確認（アカウント、トークン残、課金状況）ができていない段階で断定しない。
分からないことは「確認のうえ改めてご連絡いたします」と書き、
下書きの確認ブロックに**何を確認する必要があるか**を書いておく。

過去の実際の返信は `【マドモアゼル・aiサービス】お問い合わせいただきました件につきまして` という
件名で送られている。トーンを揃えたいときはそのスレッドを読むとよい。
