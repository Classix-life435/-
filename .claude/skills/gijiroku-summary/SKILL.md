# 議事録要約

会議の記録から、**決定事項・宿題・期限**の3つだけを抜き出して整理する。

## 入力

以下の2つを受け取る。

- **会議の記録**：文字起こし、議事メモ、チャットのログなど。形式は問わない。
- **会議の目的**（任意）：何を決めるための会議だったか。渡されていれば、決定事項の重要度の判断に使う。

会議の記録が渡されていない場合は、勝手に探しにいかず、「対象の議事録を渡してください」と聞き返す。

## 手順

1. 記録を最後まで読む。途中で要約を始めない。
2. **決定事項**を拾う。「〜とする」「〜に決めた」「〜で進める」など、結論が出ている発言を探す。検討中・保留のものは決定事項に含めない。
3. **宿題**を拾う。誰が、何をするのかがわかる形で書く。担当者が明示されていない宿題は、担当者を空欄にして残す。
4. **期限**を拾う。宿題に対応する期限を紐づける。期限が出ていない宿題は「期限の記載なし」と書く。
5. 決定事項が1件もない場合は、「決定事項なし」と明記する。無理に作らない。

## 出力

以下の3つの見出しに分けた箇条書きで返す。表は使わない。

```
## 決定事項
- （決まったこと）

## 宿題
- （担当者）：（やること）

## 期限
- （やること）：（いつまで）
```

冒頭に前置きや感想を書かない。上の3見出しから始める。

## 制約

- **発言になかった内容を補わない。** 文脈から推測できることでも、記録に書かれていなければ書かない。
- **担当者名は原文どおりに書く。** 「田中さん」と書かれていたら「田中さん」、「田中」なら「田中」。敬称を足したり外したりしない。
- 決定事項と、検討中の案を混ぜない。迷ったら決定事項に入れない。
- 記録の中で**訂正されている数値や日付は、訂正後のものを採用する。** 訂正前の値は書かない。
- 出席者の評価や、議論の良し悪しについてのコメントを書かない。
